# quantx-financial-intelligence
Quantitative Multi-Asset Financial Intelligence and Backtesting Platform

## AI Integration

This project integrates Featherless AI as the AI inference provider
for the Quant Research Copilot.

The Python quantitative engine calculates all financial metrics,
while Featherless AI generates an objective natural-language
explanation of the calculated backtest results.

Featherless API:
https://api.featherless.ai/v1

Model:
Qwen/Qwen2.5-7B-Instruct
